# نظام إدارة متجر إلكتروني (منتجات، أوضاع الفواتير، دفع)
==========================

## ملخص المشروع
----------------

نظام إدارة متجر إلكتروني هو تطبيق مكتوب بلغة البرمجة Python، يهدف إلى تسهيل إدارة المتجر الإلكتروني من خلال إدارة منتجات، أوضاع الفواتير، ودفع المستخدمين. يعتمد التطبيق على بنية بيانات قوية وواجهة مستخدم سهلة الاستخدام.

## هيكل المشروع
----------------

### مجلد المشروع

* `app`: مجلد التطبيق الرئيسي
 + `__init__.py`: ملف تعريف مجلد التطبيق
 + `models`: مجلد الموديلات (الجداول)
 + `routes`: مجلد الطرق (الواجهات)
 + `services`: مجلد الخدمات (الوظائف)
 + `utils`: مجلد الأدوات (الوظائف العامة)
* `docker`: مجلد الملفات الدوكير
 + `docker-compose.yml`: ملف تعريف الدوكير
 + `Dockerfile`: ملف تعريف الدوكير
* `requirements.txt`: ملف متطلبات التطبيق

### جداول التطبيق

* `products`: جدول المنتجات
 + `id`: الرقم التعريفي
 + `name`: الاسم
 + `price`: السعر
 + `quantity`: الكمية
* `orders`: جدول أوضاع الفواتير
 + `id`: الرقم التعريفي
 + `product_id`: الرقم التعريفي للمنتج
 + `user_id`: الرقم التعريفي للمستخدم
 + `status`: الحالة (مفتوح، مغلق)
* `payments`: جدول دفع المستخدمين
 + `id`: الرقم التعريفي
 + `order_id`: الرقم التعريفي للفاتورة
 + `amount`: المبلغ
 + `status`: الحالة (مفتوح، مغلق)

### أدوار المستخدم

* `admin`: الدور الرئيسي
 + يمكن للادمن إدارة المنتجات، أوضاع الفواتير، ودفع المستخدمين
* `user`: الدور للمستخدمين
 + يمكن للمستخدمين إضافة منتجات إلى سلة الشراء، إيداع أوضاع الفواتير، ودفع المستخدمين

## إعداد وتشغيل التطبيق
-------------------------

### طريقة 1: تشغيل التطبيق باستخدام الدوكير

1. افتح مجلد المشروع في المتصفح.
2. افتح terminal في مجلد المشروع.
3. أدخل الأمر التالي لتشغيل الدوكير: `docker-compose up`
4. افتح متصفح الويب في `http://localhost:5000` لتشغيل التطبيق.

### طريقة 2: تشغيل التطبيق باستخدام بيئة التطوير

1. افتح مجلد المشروع في المتصفح.
2. افتح terminal في مجلد المشروع.
3. أدخل الأمر التالي لتشغيل بيئة التطوير: `python app.py`
4. افتح متصفح الويب في `http://localhost:5000` لتشغيل التطبيق.
